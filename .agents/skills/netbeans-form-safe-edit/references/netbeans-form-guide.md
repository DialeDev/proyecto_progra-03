# NetBeans Form Guide

This document explains the structure of `.form` files in NetBeans and how to safely edit Swing UI components without corrupting them.

---

## `.form` File Structure

NetBeans `.form` files are **auto-generated XML** files that define the UI components, layout, and properties of a Swing `JFrame`, `JDialog`, or `JPanel`. They are linked to a corresponding `.java` file (e.g., `FrmLogin.form` ↔ `FrmLogin.java`).

### Example Structure

```xml
&lt;?xml version="1.0" encoding="UTF-8"?&gt;

&lt;Form version="1.3" type="org.netbeans.modules.form.forminfo.JFrameFormInfo"&gt;
  &lt;Properties&gt;
    &lt;Property name="defaultCloseOperation" type="int" value="3"/&gt;
    &lt;Property name="title" type="java.lang.String" value="Login"/&gt;
  &lt;/Properties&gt;
  &lt;SyntheticProperties&gt;
    &lt;SyntheticProperty name="formSizePolicy" type="int" value="1"/&gt;
  &lt;/SyntheticProperties&gt;
  &lt;AuxValues&gt;
    &lt;AuxValue name="FormSettings_autoResourcing" type="java.lang.Integer" value="0"/&gt;
  &lt;/AuxValues&gt;
  
  &lt;Layout class="org.netbeans.modules.form.compat2.layouts.DesignAbsoluteLayout"/&gt;
  &lt;SubComponents&gt;
    &lt;Component class="javax.swing.JButton" name="btnLogin"&gt;
      &lt;Properties&gt;
        &lt;Property name="text" type="java.lang.String" value="Login"/&gt;
        &lt;Property name="toolTipText" type="java.lang.String" value="Iniciar sesión"/&gt;
      &lt;/Properties&gt;
      &lt;Events&gt;
        &lt;EventHandler event="actionPerformed" listener="java.awt.event.ActionListener"
                      method="btnLoginActionPerformed"/&gt;
      &lt;/Events&gt;
    &lt;/Component&gt;
  &lt;/SubComponents&gt;
&lt;/Form&gt;
```

## Safe Editing Rules

### ❌ What NOT to Do

1. **Never edit `.form` files directly**: They are auto-generated by NetBeans. Manual edits will be overwritten or corrupt the UI.
2. **Never rename components**: Changing the `name` attribute in the `.form` file breaks references in the `.java` file.
3. **Never modify guarded blocks**: The following sections in the `.java` file are managed by NetBeans:
   ```java
   // Variables declaration - do not modify
   private javax.swing.JButton btnLogin;
   // End of variables declaration
   ```

### ✅ What TO Do

1. **Use NetBeans Design View**: Always use the **Design View** in NetBeans to:
   - Add/remove components.
   - Modify layouts.
   - Change component properties (e.g., text, size, color).

2. **Edit `.java` files safely**:
   - **Component properties**: Modify them programmatically in the `.java` file (outside guarded blocks).
     ```java
     btnLogin.setText("Iniciar Sesión");  // Safe
     ```
   - **Event handlers**: Add or modify methods in the `.java` file.
     ```java
     private void btnLoginActionPerformed(java.awt.event.ActionEvent evt) {
         // Custom logic here
     }
     ```

3. **Validate changes**:
   - Open the `.form` file in NetBeans Design View to check for errors.
   - Run the application to verify UI behavior.

---

## Recovery Steps

If the `.form` file becomes corrupted:

1. **Restore from backup**:
   - Replace the corrupted `.form` and `.java` files with the latest backup from `assets/backups/`.

2. **Reapply changes manually**:
   - Open the `.form` file in NetBeans Design View.
   - Reapply UI changes using the Design View.
   - Re-add custom logic in the `.java` file.

3. **Prevent future corruption**:
   - Always create backups before editing.
   - Use the `netbeans-form-safe-edit` skill for all UI modifications.
